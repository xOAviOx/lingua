Beginner guide

Learn Lingua, one step at a time

You only need two commands to get started: let stores a value and print shows it. Try each example in the playground.

Step 1: Print something

Type this in the code box and click Run.

print("Hello!");

Output:

Hello!

Text goes inside double quotes. The semicolon tells Lingua where the statement ends.

Step 2: Store a value

A variable is a name for a value. Here, name stores the text "Avi".

let name = "Avi";
print(name);

Output:

Avi

When you write print(name);, Lingua looks up the value stored in name.

Step 3: Work with numbers

Numbers do not need quotes. You can store them and use them in calculations.

let marks = 40;
print(marks + 10);

Output:

50

You can use + to add, - to subtract, * to multiply, and / to divide.

Step 4: Use two variables

Variables can be used together in a calculation.

let price = 20;
let quantity = 3;
print(price * quantity);

Output:

60

Try changing either number and running the program again.

Quick syntax guide

What you wantWrite this
Show textprint("Hi");
Save a numberlet score = 10;
Save textlet city = "Delhi";
Show a variableprint(score);
Do mathsprint(score + 5);

Write one statement on each line. Empty lines are fine. A variable name can contain letters, numbers, and underscores, but it must start with a letter or underscore.

Common mistakes

  • Missing semicolon: print("Hi") needs ; at the end.
  • Missing quotes: print(Hello); looks for a variable named Hello. Use print("Hello"); for text.
  • Unknown variable: create it with let before printing it.
  • Wrong line format: put each let or print statement on its own line.

The output box will show a line number when something goes wrong, so you know where to look.

What can Lingua do right now?

The current version supports variables, text, numbers, the four basic maths operators, and printing output. It reads calculations from left to right. For now, use one operator per calculation if you need the usual maths order.

Conditions, loops, functions, saving programs, and MongoDB are planned for the final phase. They are not working yet.
