Learn Lingua

This short guide shows everything the current playground can run.

1. Run your first program

Open the playground, replace the code in the box, and press Run or Ctrl + Enter.

print("Hello, World!");

The output box will show Hello, World!.

2. Make a variable

Use let, a name, an equals sign, and a value. End the line with a semicolon.

let name = "Avi";
print(name);

Names can use letters, numbers, and underscores. They must start with a letter or underscore.

3. Do simple maths

Lingua currently supports numbers and the four basic operators.

let a = 8;
let b = 2;
print(a + b);
print(a - b);
print(a * b);
print(a / b);

This prints 10, 6, 16, and 4 on separate lines. Expressions are read from left to right, so use one operator at a time when you want predictable results.

Rules to remember

  • Write one statement on each line.
  • Finish each statement with ;.
  • Put text inside double quotes.
  • Use print(...); to see a value.
  • An empty line is okay.

If a line cannot run, the output box shows its line number and an error message.

What is coming later?

Conditions, loops, functions, saving programs, and MongoDB are planned for a later phase. They are not part of the current runner.
