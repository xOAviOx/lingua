About the project

What is Lingua?

Lingua is a small programming language and a web page where you can try it.

How it works

You write a short program and press Run. JavaScript reads each line, calculates simple expressions, and shows the result of print statements.

For example, let x = 5; stores a value and print(x); shows it.

Our roadmap

  1. Build the pages with HTML and CSS.
  2. Add JavaScript interactions and form validation.
  3. Save form data to local JSON using Node.js and Express.
  4. Later, use MongoDB for the final evaluation.
