# Lingua

Lingua is our Web Programming project. It is a simple programming language with a website where you can write code and see the output.

You can try basic things like creating variables, printing values and doing maths. The website also has a docs page to help you get started and a feedback form.

## How to run

First, make sure you have Node.js installed. Then open a terminal in the project folder and run:

```bash
npm install
npm start
```

Now open [http://localhost:3000](http://localhost:3000) in your browser. You can write code in the playground and click Run to see the output.
